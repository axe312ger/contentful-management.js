      Creates a Webhook

      Parameters

      • data: {
            name: string;
            url: string;
            topics: string[];
            httpBasicUsername?: string;
            httpBasicPassword?: string;
            headers?: WebhookHeader[];
            filters?: WebhookFilter[];
            transformation?: WebhookTransformation;
            active?: boolean;
        }

        Object representation of the Webhook to be created

        • name: string

          Webhook name

        • url: string

          Webhook url

        • topics: string[]

          Topics the webhook wants to subscribe to

        • OptionalhttpBasicUsername?: string

          Username for basic http auth

        • OptionalhttpBasicPassword?: string

          Password for basic http auth

        • Optionalheaders?: WebhookHeader[]

          Headers that should be appended to the webhook request

        • Optionalfilters?: WebhookFilter[]

          Webhook filters

        • Optionaltransformation?: WebhookTransformation

          Transformation to apply

        • Optionalactive?: boolean

          Whether the Webhook is active. If set to false, no calls will be made

      Returns Promise<WebHooks>

      Promise for the newly created Webhook

      Example

      const contentful = require('contentful-management')

      client.getSpace('<space_id>')
      .then((space) => space.createWebhook({
        'name': 'My webhook',
        'url': 'https://www.example.com/test',
        'topics': [
          'Entry.create',
          'ContentType.create',
          '*.publish',
          'Asset.*'
        ]
      }))
      .then((webhook) => console.log(webhook))
      .catch(console.error)
